## 当前四档几何

| 配置值 | 界面名称 |
|---|---|
| `original` | 不添加修改器 |
| `weld_weighted` | 焊接＋加权法向（默认） |
| `local_subdivision` | 焊接＋加权法向＋身体及贴身物一级细分（约2倍顶点） |
| `all_subdivision` | 焊接＋加权法向＋全部件一级细分（约5倍顶点） |

四档均对已确认共面贴层保留 Alpha/UV 并外移 0.1 mm；这一步不添加修改器。两个细分档固定一级 Catmull-Clark 和边界/尖锐保护。焊接法线计算不减少实际导出的原拓扑。

只有局部档的面部、脖子或嘴唇未单独识别时触发补选；其余不确定部件记录黄色日志并继续。“未单独识别”可能表示合并在其它槽内，不等于模型缺失。选择按模型身份和原槽隔离。

新任务几何策略为 v5，原有任务保留 v4 或旧 v2 解释。模式、处理版本、覆盖和贴层映射不匹配时要求新任务重建；材质应用不会重建几何。完整接口见 [四档说明](CHARACTER_PBR.md#四档角色几何处理)。

## 尚未解决

- 细分后的侧面头发高光/阴影仍可能分段，保护边界不能保证消除；不以关闭投影或各向异性冒充修复。
- 全部件细分的肩袖接缝、重叠衣物及特殊拓扑仍需逐模型复核。
- 贴层自动绑定要求共面三角形、蒙皮及形态键兼容；含混宿主、独立运动和不同三角化不盲目投射。
- Neuro 隐藏眼层、部分服装亮带、玻璃光追折射及跨渲染器雾差异保留各自的待复核项。
- 公开 v0.2.0 发行包与当前源码不同；源码、新构建、部署到 UE 的 Python、原生插件及旧资产需分别确认版本。
