# UE 角色材质配置文件

v0.3.1 的源码及 Windows 包在左侧“角色设置”提供“保存 UE 选中角色材质…”、“配置应用到 UE 选中角色…”和独立撤销按钮。此功能读取 UE 当前实际材质，不依赖软件预设或原有 PBR 配置。

## 保存与应用

1. 在 UE 选中场景角色，或在内容浏览器选中 SkeletalMesh、AnimSequence、LevelSequence。场景中的 LevelSequenceActor 也可以读取其当前世界中绑定的角色。
2. 点击“保存 UE 选中角色材质…”。出现多个候选时选择具体组件／网格，保存为 JSON。
3. 在 UE 选择另一个目标，再点击“配置应用到 UE 选中角色…”，载入刚保存的文件。表格逐项显示源槽、母材质与目标槽，可手动指定对应关系。
4. 应用生成独立材质实例并只覆盖对应槽。角色网格、骨架和动画保持原样。独立撤销会检查应用后的绑定和参数；发生后续手工编辑时拒绝覆盖。

动画序列不存储材质。工具列出同骨架的预览／兼容网格，由用户确认具体目标，修改该 SkeletalMesh 的材质槽；所有引用此网格且未使用组件覆盖的对象会共享结果。场景组件应用只改组件覆盖。USD 生成组件不写回 USD，需选独立 UE 网格。

自动对应优先使用相同原 PMX 身份和原槽号，然后使用唯一的导入槽名／材质槽名／源材质名。不能唯一对应时不按位置猜测、不进行部分覆盖；在表格中明确指定目标槽后才应用。目标中未被指定的额外槽保持原样。

## 保存内容与母材质

文件保存实际绑定、父实例继承链、标量、颜色、贴图等参数数组、全局静态开关、材质基础属性覆盖及皮肤 SubsurfaceProfile 设置。皮肤高光宽度等 Profile 手工参数随文件复制，不仅是软件内置参数。用户自定义 Material／MaterialInstanceConstant 母材质可直接使用，无需登记到软件预设。

母材质、贴图、材质函数等原生 UE 资源以项目资产路径引用；JSON 不包含二进制资产。跨工程使用前需在 UE 迁移这些资产和依赖，路径需一致。缺少引用会停止应用并列出缺失项，不替换为内置材质。母材质图本身继续使用目标工程中的原生资产；文件冻结实例参数，不充当母材质图的历史版本备份。

当前 UE Python 接口无法完整读写静态分量遮罩覆盖和 Material Layers，遇到此类图明确停止，避免丢失用户参数。临时动态材质需先保存为持久化材质实例。全局静态开关、普通材质函数、继承实例及用户母材质已纳入原生验证。

只保存对应 UE 材质、目标网格或当前关卡；关卡保存期间使用 USD `NEVER_SAVE`，不保存 USD 层，也不重载当前关卡。

## 导入时复用

在“角色设置 → 导入时复用材质”选择已保存的 JSON，新角色导入后按槽位对应覆盖默认材质。选择为空保持原有行为。新任务在任务目录冻结 `character_material_preset.json`，并将文件来源哈希和快照写入任务；恢复时配置被改动会停止复用。

组合任务的各角色子任务沿用此选择，并各自冻结快照；某角色槽位不匹配时保持默认导入结果并报告失败／待复核，不冒充已应用。已成功模块的装配复用已应用结果，不重新覆盖。旧任务缺少字段时不自动载入配置。
