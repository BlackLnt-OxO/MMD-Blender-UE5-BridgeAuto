# USD 场景转换

## 导入

1. 在“素材与软件”选择 Blender 5.2、`.blend` 和目标 UE 5.8 工程。
2. “参数 → 场景导入通路”使用 **USD Stage**，设置场景参考帧、比例与所需碰撞。
3. 默认材质转换和 2K 新增烘焙分辨率适合首次检查；原始贴图不会全部被重新烘焙成 2K。
4. 连接 UE 工程，点击 **导入场景**。工具从 Blender 当前参考帧的最终求值结果导出。
5. 在“任务与日志”查看报告，按实际生成的 UE 关卡与 USD Stage 检查结果。

源文件不覆盖保存。工具创建独立 USD 包及贴图，并将运行副本复制到目标 UE 内容目录。

## 几何与实例

转换读取修改器、Geometry Nodes 和实例求值后的可见几何，保留世界变换和可对应的父层级。相同原型按条件复用；默认“USD 散件优化”把兼容重复散件组织为实例批次。

需要独立 Actor 编辑每个散件时可关闭优化。镜像、剪切、动画、单独隐藏或带特定自定义属性的散件可能保留独立结构。无法求值的对象会记录原因，不使用控制物体包围盒冒充最终形状。

场景导出以参考帧为基础，不表示任意 Blender 动画、第三方插件或模拟缓存会成为 UE 的可实时动画。

## 材质策略

- **自动**：根据有效输入选择可对应节点、局部烘焙或贴图。
- **优先 UE 节点**：适合需要保留计算关系的已支持节点；不能转换的图会报告限制。
- **混合还原**：保留可转换部分，只烘焙无法直接对应的字段。
- **完整烘焙**：用于适合静态贴图近似的材质，不能把所有视角、光照或动画相关效果变成等价材质。

基础贴图保留源 UV；额外烘焙按需要创建 UV 或投影坐标。节点组、Alpha 与透射输入参与分析，生成的 UE 材质可重新打光。用户母材质只在显式启用且参数匹配时复用；不修改原母材质。

在 Blender 中可用 `mmd_bridge_material_strategy=auto/nodes/hybrid/bake` 覆盖对象或材质的策略。涉及程序纹理、位移、混合闭包或特殊着色的近似仍需检查。

已经导入的叶片、玻璃等可通过 [局部材质切换](USAGE.md#局部材质切换) 只修改选定材质槽，支持撤销。

## 碰撞与性能

“精确碰撞”使用显示三角面，默认按相对场景尺寸过滤很小的物体。“碰撞最小尺寸 / 场景最长边”设为 0 可取消尺寸筛选，但复杂场景的碰撞会增加开销。

对象自定义属性 `mmd_bridge_collision=exact` 可强制保留，`none` 可排除。导入后用 UE 的碰撞显示与实际查询验证薄片、小物件和实例；物理表现也受 UE 项目配置影响。

“渲染减负”导入策略可减少实例、碰撞和网格体积方面的负担，程序纹理细节仍需复核。先用 [渲染与显存说明](MRQ_MEMORY.md) 中的默认设置检查，不要在大场景上直接提高所有精度。

## 刷新、停止与用户覆盖

USD 包将用户根层与工具生成的几何／材质层分开。项目内 `Scene.usda` 可保留用户覆盖；`Geometry.usda`、`ToolMaterials.usda`、几何和贴图目录属于工具生成内容，刷新可能替换。

重导出和材质重建前先保存相关 UE 改动。不要直接在工具生成层里维护需要长期保留的手工覆盖。需要改选中物体材质时优先使用 GUI 的局部切换入口。

停止会保留完成的文件和检查点；用“恢复已有任务”继续，或在相应场景任务中使用重转换入口。原始素材有变化时建立新任务。

灯光、原生雾与路径追踪对照见 [场景光影](SCENE_APPEARANCE.md)。
