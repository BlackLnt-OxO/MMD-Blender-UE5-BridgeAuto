# v0.2.0 界面改版记录

本页记录 v0.2.0 的界面调整与移除说明。操作步骤见 [快速上手](QUICK_START.md)。

## 布局

采用石墨银灰：顶部与左侧连成 `#28292d` 外框，操作区为 `#202124`，边缘 18 像素圆角。底部任务按钮归入操作区，导航分为居中的“工作区”和“专用工具”，组名不可点击。

路径名称在上方，输入和浏览按钮在下方，各占一行。常用参数默认显示，高级参数按用途折叠，场景光影全部默认折叠。原页面、按钮通路、配置键、路径记忆和旧流程入口保留。

![新版参数页](images/parameters.png)

## 交互

| 位置 | 调整 |
| --- | --- |
| 按钮、页面、下拉菜单 | 短过渡，通常约 140 毫秒；按下约 70 毫秒 |
| 高级折叠 | 160 毫秒展开／收起；布局与滚动范围逐帧变化，靠近底部时自动显示新增内容 |
| 滚动条 | 6 像素，默认 28% 不透明度；悬停、滚动和拖动时变亮，结束后恢复淡色 |
| 悬停说明 | 10 像素圆角石墨灰面板，140 毫秒淡入淡出，避开屏幕边界 |
| 标题栏与应用弹窗 | 跟随应用配色；原生窗口操作保留 |
| 文件与目录选择 | 保留 Windows 原生选择窗口 |

快速重复操作会接续动画；Qt 桌面动效总开关关闭时直接切换。应用配色覆盖自身窗口，外部 Blender、UE 和 MMD／MMM 仍由各软件绘制。

## 参数与输入

- 角色适配配置放在角色／眼睛母材质下方，改成只选菜单，增加默认官方卡通，ZZZ 位于第二项；旧配置 id 仍能载入保存。
- 官方卡通模式禁用自选母材质路径；场景通用母材质与“优先创建用户母材质实例”暂不显示，已有键和值保留。
- 母材质配置目录明确为用户映射 JSON 的目录；材质工作流补充两套规则说明。
- 后台预设提示改为“留空时自动使用生成的预设”，没有任务预设时明确报错。
- MMDBridge 安装目录说明明确指向 rintrint/mmdbridge 配套程序，增加后台自动检测；中转目录补充任务与导出文件用途。

## 移除的固定介绍

以下内容从界面固定说明区移走，不删除相应功能：

| 原位置 | 移除的内容 |
| --- | --- |
| 主窗口标题下 | 角色、场景和镜头可分别导入或走全流程，结果与错误显示在日志的总介绍 |
| 底部版本介绍 | “完整场景还原：Blender 5.2 / UE 5.8 · 旧 Blender 通路保留” |
| 场景页介绍 | 程序转换无需 AI；世界光、雾、灯光、源色彩随 USD 导入；原生雾和 PT 对照；参考帧与未知节点需复核的三段说明 |
| 场景页底部 | 先导入再渲染、CPU 参考帧、显存保护和 90%／80% 阈值说明 |
| 同上 | 手动 MRQ 需加载完整配置，单加序列不应用 OCIO 的说明 |
| 同上 | 视口与参考帧相机／源色彩的说明 |
| 同上 | PT 保留、Lumen 单独检查、切管线无需重导出的说明 |
| 同上 | 出图成功仍需人工检查对照与报告的说明 |

界面底部只保留环境部署提示：

> 首次运行需部署 Blender 5.2、UE 官方插件（USD、OpenColorIO、MovieRenderPipeline）和本工具桥接插件；安装后重启 UE。

相关操作、限制与写入范围已经整理到使用、渲染和已知问题文档，旧任务兼容行为保留。
