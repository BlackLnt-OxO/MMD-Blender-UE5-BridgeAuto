# 内置卡通渲染

v0.3.1 的“角色设置 → 角色母材质适配配置 → 内置卡通渲染”使用 CelShading_Lesson 的三层方案：基础受光、透明滤镜和描边。三层引用同一个骨骼网格，装在一个蓝图内，分别求值同一动画；Sequencer 使用相同范围和偏移驱动骨骼与 Morph。内置 PBR 仍是新任务默认。

## 参数与来源

程序随附独立命名空间下的母材质、函数、曲线和必要贴图。原工程不修改；来源哈希见 `resources/character_materials/BuiltinCel/provenance.json`，部位实例参数见同目录的 `reference_parameters.json`。本机原工程位置及原算法说明见 [原工程分析](advanced/CELSHADING_LESSON_HAIR_ANALYSIS.md)。

按识别部位继承原实例的数值及曲线行：面部使用 `MI_04_Face`、皮肤 `MI_00`、头发 `MI_15_hair01`、眼部 `MI_07`、眉睫及未知部位 `MI_08---13_Brow`、口腔 `MI_10_tough`、服饰 `MI_25---36_Texture4`。未知部位保留诊断和中性阴影，不套用皮肤参数。可在“分析与配置材质…”按原槽确认类型或补选基础色、Sphere。

- 曲线数据与对应实例的图集行不修改。
- `Brush?`、`启用边缘光` 默认关闭；后续可在 UE 的生成材质实例中手调。
- v2 的 NPR 透明滤镜母材质及新生成副本使用 **Before DOF**，与底层受光表面一起参与景深。2026-10-28 用户在当前 1017 头发上确认该设置可消除所示亮边；其它模型仍需画面复核。
- 基础图和 PMX 漫反射色共同提供原配色；没有基础图引用时保留 PMX 纯色。原图丢失则保留缺图诊断。
- 头发优先使用 PMX 已启用且有效的 Sphere，未启用时使用 `HairSpa1_psd`。其它部位仅在 PMX 实际启用 Sphere 时使用。高光颜色默认线性 RGB `(0.9, 0.9, 0.9)`，颜色 Alpha 保留对应部位实例的原混色值。
- Sphere 乘算、加算分别处理；附加 UV 模式不当作普通 MatCap。启用但缺图不改用 Cel 图掩盖问题。
- 透明度按材质实际使用的 UV 分析；基础层支持不透明、裁切和连续透明，滤镜保持原透明方案，描边同时受基础图 Alpha 与 PMX 不透明度约束。

本模式复用 PMX 真实来源及补选机制，不使用内置 PBR 的皮肤散射、微法线或粗糙度推断。六档几何选择独立保留；仅切换材质不重建网格。

## 明暗配色对照

| 选项 | 行为 |
|---|---|
| B：按部位调色（候选默认） | 亮面保留原色，第一阴影继承 Cel 对应部位实例的颜色和 Alpha 混色方式 |
| A：原色保真 | 亮面保留原色，第一阴影采用线性 RGB `(0.6, 0.6, 0.6)`，Alpha 为 0 |

两组选项均保留第二阴影及曲线。`BaseColor`、`ShadowColor` 的 Alpha 参与去饱和或颜色混合，并不是表面透明度；不要把最终目标颜色直接重复乘入。明暗由底层受光后屏幕亮度决定，深色衣物可能更容易进入阴影。原曲线仍会改变输入颜色，因此“保留原色”不表示最终屏幕像素与贴图相等。

## 使用与验证边界

新字段 `character_cel_color_mode` 为 `role` 或 `neutral`，随配置及组合子任务保存。修改配色、来源或母版版本后新建任务；缓存不会混用两组算法。旧任务及既有资产不自动迁移。

当前母版命名空间为 `/Game/MMDBridge/BuiltinCel/v2/`。重新连接工程只安装当前版本，保留已安装的 v1 及其手调参数；新母版规则需要新建转换任务。v1 随附文件保留作旧版来源记录，不再作为新任务的安装入口。此默认不修改独立自建材质或其它透明场景材质。

三层方案需要包含 `MMDBridgeCelCharacterActor` 的新版 MMDBridgeCharacter Runtime 插件。BuildId 相同只表示引擎兼容，不表示旧 DLL 已包含新类型；连接工程后安装实际新版二进制，已经运行的 UE 需要保存并重启。

本批以 1017 的独立 Miku A／B 场景作为首轮验收，复用已有的加权法向网格和动画。源网格的旧 Blender／FBX 验证不计为本批重跑。材质生成、原生加载和画面比较分别记录，画面确认前保留 `needs_review`。透明排序、景深、顶点色 B、极端视角 MatCap 和不同模型的适用性均需逐项复核。

2026-10-28 首轮：229 项 Python／Qt 回归、安装检查及 14 组 Blender 原生几何夹具通过。1017 的 40 槽三层蓝图已保存重载；0、3030、6060 帧的 741 根骨骼、85 条表情曲线和三层移动通过对照，表情与 UE 原生压缩动画求值的最大误差为 0。原始曲线与压缩曲线约 0.000783 的差异单独记录，没有改写动画。原尺寸截图为第 4119 帧的四视图 A／B，以及第 3030 帧的睁眼正面 A／B，共 10 张；本机回执位于 `work/builtin_cel_20261028_01/`，测试关卡为 `/Game/MMDBridgeTests/BuiltinCel_20261028_05/Maps/CelComparison`。

该 Miku 有 21 槽启用有效 PMX Sphere，包括三个头发槽，因此按“PMX 原图优先”使用原图；未启用的其它槽不添加 MatCap。此样本没有对默认 Cel 头发备用图作跨模型画面验收。未知部位继续保留复核诊断；A 更接近原配色，B 的皮肤更暖、头发暗部更蓝，最终默认仍等用户选择。

## MRQ 运行状态

三层角色的网格、材质数组和动画引用保存在原生角色属性及蓝图默认值中。MRQ 会创建独立运行世界，编辑器临时的顶点色覆盖、材质槽显隐或选择状态不一定随之保留；自建的叠层蓝图需要自行保存并在运行时恢复这些状态。不要只凭编辑器中静止的一帧判断最终渲染。

2026-10-29 旧舞台的独立 `BP_CelHairLayers` 曾在 MRQ 中丢失滤镜顶点色控制和槽位显隐；当时两盏角色灯仍存在，已通过该舞台蓝图的运行时初始化恢复。这不是工具内置 `MMDBridgeCelCharacterActor` 的同一次实现，不能将其中的固定槽号或全白顶点色覆盖移入通用转换。内置模式应逐项对照保存重载、骨骼与表情、材质绑定、顶点色和 MRQ 运行状态，保留模型原始数据。

2026-10-30 在独立 UE 5.8.2 工程复核：当前源码的三层蓝图生成及第二进程重读通过；A／B 两组在 0、3030、6060 帧的 741 根骨骼、85 条表情曲线与压缩源动画一致，原始曲线约 0.000783 的压缩差异单列。9 帧、640×360 的 MRQ 短测使用 Frame Open、4 时域×2 空间、None，运行中的材质绑定、槽位显隐、光照通道及可见角色顶点色与编辑器一致，未复现旧舞台蓝图的临时控制丢失。该检查不改写源顶点色，不代表 A／B 外观已获确认，也不替代全片、其它采样方式或其它模型的画面验收。本机回执位于 `work/recent_features_acceptance_20261030_01/`。
