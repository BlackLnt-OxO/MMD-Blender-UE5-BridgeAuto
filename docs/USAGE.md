# 使用指南

## 一键全流程与独立导入

**走全流程**要求 PMX、动作 VMD 和 Blender 场景同时填写，口型和镜头 VMD 可选。选择默认 MMDBridge 角色通路并准备对应软件后，工具串联角色、场景和镜头任务。

主方案以 Blender 5.2 为主介绍；当前 v0.1.0 的角色版本检查及软件配置见 [安装说明](INSTALL_WINDOWS.md#当前-blender-版本兼容说明)。旧的“Blender / FBX（不烘焙物理）”流程已弃用，曾在 4.3 测试，保留入口供既有任务使用。

三个独立按钮适合只处理一项或分别检查结果：

| 按钮 | 输入 | 不会处理 |
| --- | --- | --- |
| 导入角色 | PMX、动作 VMD，可选口型 VMD，上游 MMDBridge 目录 | 已填写的 Blender 场景与镜头 |
| 导入场景 | `.blend`、Blender、UE 工程 | 已填写的角色与 VMD |
| 导入镜头 | 镜头 VMD、Blender、UE 工程 | 已填写的角色与场景 |

首次使用 UE 工程，先按 [安装说明](INSTALL_WINDOWS.md) 安装桥接和编译视口小插件。在“素材与软件”连接目标项目。工具不会替你创建完整的用户 UE 工程。

## 中转文件与配置

**临时中转目录**保存任务记录、恢复点、贴图与导出结果。留空则自动创建桌面 `Middle_*` 目录。用“打开任务文件夹”查看实际位置；`MMDBridge_Jobs` 下的 `job.json` 是任务入口。

“保存配置／载入配置”用于复用输入和参数；“恢复已有任务”读取已有任务继续处理。恢复时仍需原任务目录、源素材和 UE 工程，移动或删除其中一项会影响恢复。更改源文件后应创建新任务。

**旧 FBX：角色工作文件**仅在选择“旧 Blender / FBX（不烘焙物理）”时显示，用于打开已有 `.blend` 作为角色处理起点，不负责指定中转目录。默认 MMDBridge 通路不读取它。

## 物理骨修复

有些 PMX 的裙子、头发或饰品骨骼由刚体驱动，但没有登记到任何“显示枠／Display Frame”。实时物理可能正常，部分烘焙工具却不能把这些骨骼的运动写成完整关键帧，导出的 VMD 因而丢失相应运动。

**默认 MMDBridge 角色流程（包括一键全流程）会自动处理：**读取 PMX，检查物理骨的显示枠登记，按需补齐缺失条目，并回读校验任务中的 PMX 副本；后续烘焙和 Blender 导出使用该副本，不覆盖原始模型。没有物理骨时跳过物理烘焙。无需先在独立页面手动修复。

需要单独检测或输出修复文件时，在 **PhysicsBakeFix** 页面：

1. 选择 PMX，点击 **① 检测（不写文件）**。
2. 查看检出的物理骨与显示枠问题，确认是否需要修复。
3. 点击 **② 修复并输出新 PMX**。
4. 使用输出的 `<原名>_PhysicsBakeFixed.pmx` 进行后续烘焙。

判断依据是刚体与骨骼的关联及物理模式，不是名称。修复只补充缺失的显示枠条目，不改刚体、Joint 或骨骼层级，不覆盖原始 PMX。它修复的是登记问题，不能替代真实物理烘焙或修复所有模型问题。

该页面是独立工具，不会自动启动角色导入；默认角色流程的自动检查与修复不依赖该页面的检测结果。

## 镜头自动切分

VMD 镜头常把多个镜头写在一条轨道里。当位置、方向或焦距突然跳变时，连续轨道和渲染的时间采样可能在跳切处产生不想要的插值、运动模糊或画面混合。**CameraCutAuto** 用切点把序列划成 Camera Cuts，便于逐镜头检查和渲染。

1. 在 UE 的 Sequencer 打开要处理的 Level Sequence，并连接对应 UE 工程。
2. 到 **CameraCutAuto**，点击 **开始 Probe + Detect**。
3. 工具先检查序列与接口，再显示候选切点；这时还没有自动执行 Bake。
4. 人工确认帧序列，可以添加帧、删除填写帧或多选删除；“恢复 Detect 结果”会恢复本次检测列表。
5. 点击 **确认帧序列并 Bake**。完成后自动运行 Verify，结果与错误写入“任务与日志”。

已有非本工具生成的多段 Camera Cuts 会先检查，避免重复切分。检测结果需要复核，真实的快速移动不一定是跳切。Verify 检查轨道结构，最终效果仍应检查 MRQ 的实际输出。

## 场景转换

在“素材与软件”选择 `.blend`；“参数”中保持 **USD Stage** 和默认材质转换；“场景还原”中按需设置灯光、雾和曝光。点击 **导入场景**。

**场景参考帧**决定最终几何和已缓存模拟的形状。工具转换 Blender 求值后的结果，不要求先手动应用所有修改器。材质优先保留可对应的输入，不支持的字段按策略局部烘焙或报告限制。

导入后可调整 UE 灯光和材质。需要对照时选择已转换任务，分别渲染 Blender／UE 参考帧，再生成对照图。参考帧使用源活动相机；先在 Blender 配置好相机、画幅和参考帧。

更多说明见 [USD 场景教程](USD_SCENE_TUTORIAL.md)、[场景光影](SCENE_APPEARANCE.md)。

## 局部材质切换

例如叶片被误作玻璃时，可以只重建选中的叶片材质槽，而不重新导入整场景：

1. 在 UE 保存相关关卡和资产，单选或多选目标物体。
2. 在工具的 **场景还原** 页面点击 **分析／切换 UE 选中物体的材质…**。
3. 工具读取当前选择并自动匹配本项目的转换记录，无需先选任务。
4. 查看分析结果，勾选要修改的材质槽。花盆、边框等不需要修改的槽取消勾选。
5. 选择合适的表面逻辑并应用，回到 UE 检查效果。

可选逻辑：**不透明、镂空遮罩、薄片透光＋镂空、透射折射**。默认预选当前分析出的逻辑；多选结果不一致时预选不透明。未找到转换记录的槽会说明原因并禁止勾选；任意外部 UE 材质不能凭空恢复 Blender 节点。

强制模式仍走主材质转换管线，但会覆盖表面分类。源节点没有足够的遮罩或透射数据时，不保证强制后的外观符合预期。

不满意时点击 **撤销上次材质逻辑切换**。撤销恢复该批次之前的材质绑定和工具覆盖，不是清除原先已有的覆盖。切换后又手工修改相关绑定时，工具会检查状态并拒绝盲目覆盖；先处理提示再继续。独立网格体的成功切换会保存当前关卡，所以应用前必须先保存自己的其它改动。

## MMM 物理烘焙（已弃用）

**已弃用表示暂时停止维护，不表示已删除或禁止使用。** 默认角色流程推荐 MMDBridge；MMM 页面仍保留环境准备和遥测功能。

从 [MMM 官网](https://sites.google.com/site/mikumikumovingeng/) 下载 **MikuMikuMoving version 1.2.9.2 — 03 Jun 2018 — 32bit/64bit** 条目中的 **64 位版**。

在页面选择 MMM 目录，可准备隔离 Runtime，再安装本项目的遥测插件。Windows 发行包包含遥测插件；源码方式运行时按其 [构建说明](../plugins/mmm/MMDBridgeMMMPlugin/README.md) 编译。隔离副本可避免修改原安装目录；卸载入口保留。页面不自动操作 MMM 的物理烘焙，烘焙仍在 MMM 中手动完成。

## 渲染、停止与恢复

后台渲染沿用 UE 已保存的关卡、序列与 MRQ 预设。先保存并关闭编辑器，再选择预设和范围，详见 [后台渲染](background_render.md)。

“停止任务”与“停止后台渲染”属于不同入口。停止后已写入的结果保留，等待进程与回执完成后再开始其它操作。“恢复已有任务”用于转换任务；后台渲染使用对应恢复按钮。

未完成、失败或“需复核”不等于完整成功。看见画面不代表全部输入都已经正确还原，最终仍要检查 [已知问题](KNOWN_ISSUES.md)。
