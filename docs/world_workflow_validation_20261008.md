# 世界场景转换流程优化

本轮优化共用的导出、导入、重载与后台渲染流程，没有加入港口物体名称或路径判定。

## 保持的行为

- `blender_materials.py`、`ue_materials.py`、`material_policy.py`、`ue_foliage.py` 未改动。主方案、白模补修、树叶默认策略保持原样。
- 物理灯光单位换算、默认灯光配置、雾密度、体积采样格、环境 HDR 与背景接线、曝光、OCIO、默认 Lumen 控制值保持原样。
- 不自动切换所有灯到阴影贴图，不自动降低雾密度，也不提高整个场景的体积分辨率。
- 已导入场景不会因为诊断报告而重建其材质。新导入使用同一套主方案；新增体积统计只记录现有采样结果。

## 流程变化

| 环节 | 变化 | 作用 |
|---|---|---|
| Blender 体积导出 | 记录有效采样数量、活动体素、消光/自发光峰值及散射相函数范围；拒绝非有限系数 | 区分活动散射、空体积、吸收和采样近似，不根据这些记录自动改变网格 |
| UE 导入 | 报告实际体积组件、材质绑定、步长、阴影偏置和照明缓存下采样 | 密度网格与照明缓存精度分开记录，不把二者当作表面阴影分辨率 |
| UE 编辑器维护 | 对场景清单使用最多 16 项的只读缓存，时间戳、创建时间或大小变化即失效 | 减少每次维护重复解析 JSON；不缓存组件和用户材质覆盖 |
| 后台渲染 | 在加载及 MRQ 真正开始输出帧时记录实际世界状态 | 拿到渲染预设应用后的状态，检查预期体积和灯光是否缺失 |
| 灯光验证 | 除颜色、强度外，核对阴影、体积参与、漫反射/高光、IES/Light Function 绑定 | 数量一致不能代替配光检查；参数差异作为复核项，允许动画和人工调整 |
| 雾阴影诊断 | 标出实时异质体积与表面光追阴影路径可能不一致的灯光 | 仅为风险提示，不能宣称已证明漏光；已知无散射的体积不参与该诊断 |
| 渲染器切换 | 工具生成的预设在临时副本中同步所选渲染器，帧契约使用实际 `FinalImage` 或 `PathTracer` | 修复选了路径追踪却保留旧通道，以及有效路径追踪帧被误判缺帧的问题；自定义预设保留其通道 |
| 渲染恢复 | 指纹包含世界运行时代码，恢复时核对通道；缺失预期世界资源不能凭图片通过 | 避免跨准备逻辑或跨渲染器混用输出帧 |

旧体积缓存没有新统计时，报告为未知，不触发补烘焙。`-game` 若没有 Python 属性别名，读取原生 `StepFactor` 等属性名；两种名字都不可读时保留未知，不猜测数值。

## 验证证据

证据目录：`work/world_appearance/workflow_20261008/`。

- 43 项针对世界转换与后台渲染的便携测试通过。
- Blender 5.2.2 原生世界回归通过：嵌套组实例、常量灯光表达式、角度表达式、IES、相机/照明分支 HDR、诊断异常保留 HDR、混合 HG 及新增统计。8³ 混合雾仍为逐体素消光 0.005，散射加权 HG 0.375。
- Blender 原生缩放程序化体积、静态 VDB、表面和体积共存、非闭合容器拒绝回归通过。
- UE 5.8.2 原生重载验证通过：港口 64 个灯光参数匹配、两个体积材质绑定有效、临时预设可以来回切换两个通道、原预设不变。
- 后台真实渲染：小测试场景 640×360 路径追踪通过，实际通道 `PathTracer`；港口 640×270 Lumen 验证帧通过，运行时 64 灯、两个体积有效，无材质回退。这是技术验证帧，不能替代完整分辨率的视觉验收或性能测量。
- 后续港口复核加载阶段触发 90% 显存保护，未输出帧，没有 GPU 崩溃证据。同期有游戏进程占用资源；没有修改或停止该进程。失败记录保留于 `harbor_lumen_final_result.json`，不能据此声称新代码的画质或性能发生变化。
- 单独的 `-game -NullRHI` 原生检查通过：四个体积 Python 别名确实不可读，通过原生属性名读到 1、2、0.5、2；没有渲染、没有改动组件参数。
- 场景清单读取小测量：128,140 字节 JSON，20 次普通读取平均约 2.06 ms；200 次缓存热读取平均约 0.27 ms。仅衡量解析边界，不代表 UE GPU/视口提速。
- MyGO、Railway 630 项受保护资源及本轮受保护港口文件哈希不变；源 Blender 文件不变。主方案相关代码哈希不变。

## 后续画质优化的入口

雾的遮挡方向性仍须独立验证。下一项应使用可重复的小场景：不透明遮挡物、均匀局部雾、普通点灯，以及 IES/Light Function 灯各一组，比较同机同帧的实时阴影路径与路径追踪。只在这种对照证明有效且开销可接受后接入可选择的修正，不把单个港口的观感当成修改所有场景默认值的依据。

当前提交完成的是流程可靠性与诊断优化，没有宣称消除了 Lumen 与 Cycles 的雾光差距。
