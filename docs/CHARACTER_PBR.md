# 内置PBR角色

2026-10-19 的真实链路、当前默认值与保留限制见 [角色 PBR 验证记录](CHARACTER_PBR_VALIDATION_20261019.md)。

角色母材质预设的第二项为“内置PBR角色”，新任务默认使用这一项。已有任务按保存的预设恢复，旧任务未保存预设标识时继续使用原有自动匹配行为。

新任务默认勾选“导入角色时使用柔和阴影”，导入前可以关闭；“皮肤散射默认值”默认选择“中间散射”。面部／身体散射强度默认 0.27／0.35，颜色取原暖色与柔和实验分支的参数中值，粉嫩度仍为独立的 0.3。选择“原暖色散射”可使用先前配置。旧任务缺少这两个字段时恢复原灯光和暖色散射，已保存角色不自动改变。详细数值、场景灯光处理和 UE 调节方式见 [柔和阴影与皮肤散射](CHARACTER_PBR_SOFT_SHADOW.md)。

## 输入与默认行为

选择 PMX 后，点击角色区域的“分析与配置材质”。窗口按原始材质槽显示名称初判类型、PMX 透明度、Sphere 模式、可关联的附带贴图及待确认项。实际转换时，Blender 按各材质使用的 UV 区域分析透明度，避免共用图集的其它区域干扰分类。对 Eyes 等含义不明确的名称，还会按实际 UV 颜色分布复核眼白类型；手动类型优先，手动更换基础贴图后不沿用旧图的颜色判断。

- 基础色优先使用 PMX 实际引用；没有基础贴图的纯色材质保留 PMX 固有色。
- 缺少法线、粗糙度、金属度等专用贴图时，使用对应材质类型的默认参数。法线回退使用随程序提供的恒定中性法线，避免把引擎示例法线的凹凸误加到角色上。
- 附带贴图只有在名称明确关联且唯一时自动绑定。LightMap、ORM 或其它打包遮罩的通道未知时，列为候选，需手动选择用途和通道。
- MatCap 跟随 PMX 启用状态，保留 Sphere 乘算／加算模式；目录里仅存在贴图不会启用。可以按槽位强制开启或关闭。
- 眼睛使用原有网格，不增加角膜几何。虹膜视差需要明确的虹膜遮罩，默认深度为零。
- 头发使用 UE 各向异性高光。附带流向图优先；没有流向图时按连通发片的几何长轴投影生成 UV 流向图，重叠或退化区域使用 U／V 主方向并标记视觉复核，可在窗口中旋转修正。
- 原 PMX 透明度和隐藏参数原样传递，透明、自发光和材质类型分别控制。参数保留后仍需检查实际画面；跨角色测试发现 Neuro 隐藏眼层在现有路线中仍可见，记录为待修项。

材质分类及默认数值是可编辑预设，不能替代对未知模型的视觉检查。自动识别无法确定具体材质时，使用通用 PBR，可手动指定皮肤、头发、眼睛各层、布料、金属、皮革、塑料、橡胶和玻璃等类型。

## 分类来源与版本

分类版本为 v9，当前材质着色版本为 v9；两者独立记录。着色 v9 修正自动鼻部散射遮罩、眼部微弱自发光、牙齿釉质层和半透明布料的纤维光泽。新母材质名称含 `_S9`，缓存签名包含着色版本，避免复用旧着色图。`classify()` 仍返回类型字符串，19 类标识、按模型 SHA256 和原槽位索引保存的手动覆盖格式不变。旧分析缓存缺少新增分类证据时仍可打开，已保存的旧角色不会自动改写。

手动类型优先；自动判断依次读取原材质 `name`、PMX 日文字段 `mmd.name_j`、英文字段 `mmd.name_e`。每个字段先统一全角字符并拆分英文单词，再按规则优先级匹配。明确的原部件名优先于后面的英文导出标签，同一字段中的金属、玻璃、塑料及眼睛分层等具体规则仍优先。例如 Ribbon 配上英文 Hair 标签时使用布料，FaceBrow 使用眉毛／睫毛，安全裤使用布料，ShortsMetal 保持金属；Shoes 和普通扣件保留通用 PBR，需人工复核。

现有“来源与待确认项”区域显示命中字段、词段、手动覆盖来源和冲突提示。未识别名称、通用材质与规则冲突不会自动获得视觉验收。贴图后缀关联、局部眼白颜色复核、PMX／UV 透明度及 MatCap 来源仍分别处理；程序不会全面识别贴图中真实的物理材质。

分析窗口的材质列表用黄色文字标出未识别、规则冲突或缺失资源。选中一行，在右侧“材质类型”选择实际类型后，沿用原基础色、透明度和 MatCap，重新匹配唯一的同名辅助贴图，并更新内置微法线、织纹和粗糙度细节。文件栏的自动路径以占位文字显示，悬停可看完整路径；不会把自动来源写成手工文件覆盖。手工文件、通道和反转优先保留。手动确认类型后解除分类黄色提示，资源缺失仍保留黄色及回退诊断。

补充 `齒`、`Eyehi`、`Trousers`、`スウェット` 等已验证别名，以及日文明确的金属、玻璃、塑料、皮革和橡胶名称；例如 `スウェットパーツ(メタル)` 保持金属。`スーツ` 只表示服装用途，继续待确认。明确命名为机器人或机械模型时，“身体／body／arm”等弱部件名不再直接判为皮肤，改为通用 PBR 待确认；不会据此猜成金属或塑料。

跨角色验收目录为 `work/character_pbr_20261018/CrossCharacter_v9`。每个样本有独立工作目录和 UE 资产根，保存规则修改前的原始自动分类及贴图引用。覆盖矩阵分开记录样本存在、原生编译与画面复核，隐藏或被遮挡的槽不会仅凭类型名称算作画面通过。GenZ v8 现有资产继续冻结；对它重新分析所得的 v9 分类不会自动写入已保存的 v8 角色。

UE 5.8 的半透明玻璃明确使用 IOR 折射模式，连接折射根输入前先完成角色 usage 编译，避免新连接与旧缓存状态冲突。这是跨角色透明罩测试发现的兼容修正，后续着色版本继续保留。

## 眼睛与牙齿

默认配置 v2 将虹膜、眼白和眼睛高光的 `EmissiveStrength` 分别设为 0.35、0.20、0.30，提高阴影中的可见度；当前配置 v3 保留这些数值，更早配置为 0.08、0.04、0.1。可在分析窗口“自发光强度”或 UE 材质实例中调整，0 关闭。没有独立自发光图时，使用原眼部基础色作为自发光颜色，保留瞳孔、虹膜纹理和高光的对比；明确绑定自发光图时以该图为准。原透明遮罩、原 PMX 可见性、清漆层和虹膜深度遮罩继续生效。熄灯图允许这些眼层发光；关闭眼部自发光的同机位图另作零光验证。材质名中的 `_D3` 与元数据 `PBRDefaultsVersion` 区分当前默认配置修订，着色算法仍为 v9；显式手动覆盖优先。

牙齿使用低强度釉质清漆和原贴图颜色，关闭表面微噪声，默认没有自发光。口腔遮挡和灯光仍可使牙齿变灰或偏色，不能仅凭口内颜色判断贴图缺失。修正分类不替换牙齿贴图，也不将其强制涂白。独立嘴唇使用面部类型，导入时优先继承共用图集的面部参数；唇色、透明度及显式手动覆盖保留，后续单槽修改仍独立。

## 皮肤、织物与水渍

第5版将皮肤毛孔、布料织纹、皮革纹理和头发细节分开。皮肤与布料都带有细微粗糙度变化；布料还使用 Cloth 纤维光泽。Blender 根据网格与实际 UV 面积估算细节尺寸，显式修改“细节重复”优先于自动估算。

第6版增加“缎面／领带”和“丝袜”类型。普通不透明布料保留 Cloth 织纹与纤维光泽；领带使用较平滑的缎纹及各向异性反光；丝袜使用独立的细密针织法线、粗糙度和覆盖遮罩。纤维高光方向按实际 UV 重力方向估算，可手动旋转。

着色 v9 的半透明布料也使用 Substrate Cloth/Fuzz，保留原 PMX alpha 与表面透明光照，不再绕过纤维光泽分支。`Fuzz`、`FuzzBrightness`、`Roughness` 和织物粗糙度变化继续可调；是否适合具体服装仍需结合原纹理、法线和实际画面确认。

选择丝袜后，“丝袜织物覆盖”控制透肤程度，“丝袜侧面加密”控制掠射角处变深的程度。此效果需要半透明模式以及丝袜下面的皮肤网格。原 PMX 透明度作为覆盖倍率参与计算，原本隐藏的槽位保持隐藏；手动不透明或镂空模式不会自动改成半透明。覆盖模型是角度与针织遮罩的表面近似，没有新增纱线几何。丝袜、领带的参数仍按模型和原槽位保存，可使用单槽应用与撤销。

“丝袜厚度”在程序中提供薄／中／厚三个预设，数值分别为0.35／1／2.5。在 UE 中打开角色 stocking 材质实例，勾选 Hosiery 分组下的 HosieryThickness，即可在0至3之间连续拖动或输入任意小数，也可用动态材质实例连续赋值。程序会保留设置文件里已有的自定义数值，点击预设才替换它。

第8版将厚度改为线性覆盖倍率：先按原织物覆盖、侧面加密和PMX透明度求出标准覆盖，再乘 HosieryThickness，最后限制到0至1。厚度0隐藏丝袜表层，1保持原标准覆盖，达到1的区域完全遮蔽后不再增加不透明度。这是相对覆盖参数，不是毫米或丹尼尔数，不改变网格；最终受光亮度不等同于参数的线性值。

旧第7版把厚度放在透光指数中，最终还受PMX透明度上限限制，导致厚档正面仍透肤，侧面更黑，中间出现浅色带。此样本的MatCap关闭、镜面高光关闭及0.3mm外移对照均未消除该带，增加遮蔽才消除。第8版只改丝袜厚度的计算，保留原左右腿不同的丝袜覆盖范围。

普通布料提高绒面纤维权重、收弱光滑表面反光，并提供“纤维提亮”和“织物粗糙度变化”，黑色纤维也能有少量反光。领带保留纤维方向，同时调宽、收弱亮面高光。选择皮肤或面部后，“皮肤粉嫩度”范围0至1，默认0.3；0保留原基础色，增加后带柔和粉色。原面部彩绘、鼻部散射遮罩、水渍开关均保留，粉嫩度不增加散射距离或自发光。

纤维方向使用 UE 的 [Anisotropy 和 Tangent 输入](https://dev.epicgames.com/documentation/unreal-engine/material-inputs-in-unreal-engine?lang=en-US)，半透明丝袜沿用 [Surface ForwardShading](https://dev.epicgames.com/documentation/unreal-engine/lit-translucency-in-unreal-engine?lang=en-US)。最终效果仍以固定工程的实际编译与渲染为准。

选择皮肤或面部材质后，可勾选“皮肤水渍 → 启用水滴与流痕”。默认关闭；水渍强度、水滴重复、流痕方向、水滴凸起和水面粗糙度分别可调。这些设置按当前模型与材质槽保存；“应用当前材质到UE”和撤销使用原有单槽流程。UE 材质实例对应开关为 WetEnabled（0关闭、1开启）。全角色转换配置也可通过 character_pbr_options.params.WetEnabled 指定所有皮肤槽的默认状态。

水滴与流痕使用随程序分发的确定性表面法线和遮罩，随角色 UV 保持附着，并响应真实灯光。它属于皮肤表面效果；轮廓外的水滴体积和真实水体折射需要额外几何。流痕方向按各材质的 UV 重力投影均值估算，UV 镜像、重叠或不同方向的岛仍需视觉检查，可手动旋转。

面部和身体使用独立 Subsurface Profile，明确启用 Burley 和 Mean Free Path 参数，默认红通道距离分别为0.18cm和0.32cm，避免较宽散射抹去小尺寸鼻部的明暗。源模型网格、骨架和表情保持原来源。

“鼻部等细节保留”控制平滑面部散射遮罩的作用，0 为均匀散射，1 为全部应用当前遮罩。旧自动遮罩在鼻部将散射乘到接近零，多个角色出现集中暗斑；着色 v9 对自动生成的遮罩先应用“自动散射遮罩下限”`SSSMaskFloor`。当前默认配置 v3 按用户选择将下限恢复为 0.9，使自动局部调制在 0.9 至 1 间变化，再乘原散射强度；v2 的 0.7 对照保留为历史验收记录。面部中值散射仍为 0.27，粉嫩度仍为 0.3，鼻型、网格法线和基础色不变。

下限 0 可复现旧自动遮罩的强对比，1 表示不压低局部散射；“细节保留”仍可独立关闭。`GeneratedSSSMask` 仅对程序生成的遮罩开启，手工和明确命名的附带遮罩不受自动下限限制。可在“面部散射遮罩”字段指定自己的遮罩和通道。自动定位按标准 MMD 正面轴寻找鼻部，找不到合理区域时保留均匀散射并记录原因；未知模型仍需视觉复核。

## 修改与保存

窗口中的文件字段留空表示使用自动来源。显式指定文件后，选择 RGB 或单独的 R/G/B/A 通道，必要时反转。法线、粗糙度、金属度、透明与方向图使用数据颜色空间，基础色、MatCap 和自发光颜色按颜色贴图处理。

每个模型的覆盖按 PMX 内容哈希和材质槽索引保存，并随任务及软件路径配置保留。更换为内容不同的模型不会套用旧模型的槽位覆盖。

导入之后，在 UE 中选中对应角色，可从窗口点击“应用当前材质到UE”。操作创建新的材质版本，只替换当前选中角色的匹配槽位；“撤销上次UE材质应用”恢复上次绑定。原共享材质保留，遇到后续人工编辑时停止覆盖。新增透明遮罩后，实时应用时需明确选择镂空或半透明；重新生成角色可以重新按 UV 自动分析。

## 白模与兼容

关键贴图缺失、损坏，或材质设置不能转换、UE 编译失败时，对应槽位使用白模，并在诊断中记录原因。可确定的透明遮罩和原始隐藏状态会保留，其它材质继续处理。

仅缺原PMX的Sphere／MatCap效果贴图时，保留可用的基础色和PBR表面，状态为`needs_review`；诊断中的`missing_effects`记录原引用及回退方式。MatCap选择仍是“跟随原PMX”，并记录源模型请求了该效果但资源不可用，不绑定替代图。缺少基础贴图、无效的手动绑定及编译失败仍使用白模。配置窗口的槽位列表区分“缺效果图，待复核”和“缺图白模”；缓存复用也保留缺效果图诊断。

材质由程序在目标工程生成，支持编辑母材质和实例。无需复制测试工程中的手工材质，不依赖运行时 AI。当前目标为 UE 5.8、桌面 DX12/SM6、Lumen 与现有 Substrate Blendable 配置。

## 首阶段验收

截至 2026-10-18，GenZ 外观冻结在第8版丝袜线性厚度候选，目录 work/character_pbr_20261018/Hosiery_v8；分类与跨角色测试已进入第9版，最终证据见 CrossCharacter_v9/RESULTS.md。第8版49材质编译成功、白模0，程序只提供薄／中／厚三个厚度按钮；UE实例的Hosiery分组暴露HosieryThickness、滑杆0至3。厚度0、0.65、1.23456、1.85、2.5、3均通过单槽应用、保存重载、撤销，其余48槽绑定不变；动态材质实例另验证5个任意数值。该阶段119项针对性测试通过。原49槽的参数、贴图字节、MatCap及透明模式与第7版一致，只有丝袜厚度的覆盖计算改变；源PMX及1085个旧资产／工程配置文件哈希保持。6张原生1440p对照图、7组原生诊断和参数回执见同级review_receipt.json。程序验证不代表审美通过。

第7版的布料／粉嫩皮肤及水渍能力继续保留，历史图片在 work/character_pbr_20261018/FabricRosy_v7/Review。该版收弱布料亮面并改进纤维反光，皮肤增加粉嫩度；厚度与粉嫩度／水渍组合曾通过单槽应用、保存重载和撤销。黑色裙裤仍取原深色贴图，15个通用材质及部分扣件尚未逐个精修。本轮没有重新宣称这些材质全部完成精修，也没有重跑水渍画面。

第5版围绕鼻部明暗、皮肤毛孔、水滴与流痕开关，以及独立布料织纹和纤维光泽展开。原网格、骨架、眼影面片与 PMX MatCap 开关保留；鼻部使用平滑局部散射遮罩，面部其余区域保留柔和散射。

## 可选焊接与加权法向对照

`scripts/validate_character_pbr_blender.py`增加实验参数`--mesh-finish weld_weighted --weld-distance 0.0001`。普通转换及夹具默认不处理网格。PMX通常导入为一个网格；实验按原材质槽拆成部件，每个部件按Weld、Weighted Normal顺序处理，保留原Armature变形。默认焊接距离为导入后Blender空间的0.1mm，加权方式为面面积、权重50，保留锐边。

输出的`Character.blend`保存逐部件的修改器计算网格，另保留原拓扑作为导出网格。通过原面角索引将计算结果回传为自定义法线，原顶点、UV、蒙皮、形态键坐标及相对关系保持；被焊接消除的微小面保留原法线。此方案用于比较焊接平滑及加权法向的外观，不减少UE导出网格的顶点数。直接应用拓扑修改器或重建形态键的初轮方案在UE中出现表情破裂，已拒绝作为有效流程。

`scripts/prepare_character_pbr_mesh_comparison_ue.py`将实验网格导入独立UE根，复用原始分支已编译的母材质和相同参数，并按纯数值对齐相机、灯光尺寸及位置。它保存重载后核对机位、槽位和表情目标，同时检查原始分支文件哈希。材质槽按原名匹配，运行时诊断使用PMX索引到实际UE槽位的映射。该流程用于对照，尚未默认用于日常角色转换。

该阶段额外模型、安比基础色回退及粉嫩度0／0.3／1对照证据见`work/character_pbr_20261018/ExtendedModels_v10/RESULTS.md`。该历史批次的分类器为v9、着色为v8；`v10`是测试批次名。2026-10-19 的后续材质修正与原生对照保存在 `work/character_pbr_20261019/MaterialCorrections_v1`。
