# 已知问题

## Ray Traced 半透明黑玻璃：暂缓

部分 Substrate 玻璃在 Ray Traced 半透明、包括开启光追折射时出现黑玻璃；多层与立体交界也可能出现异常。透射兼容、穿越次数、几何与光照都可能影响结果，尚未确定统一解决办法。

常规使用以 Lumen 为性能目标、PT 为效果参考。把材质切到“透射折射”不会自动消除渲染器本身的限制。同一视图的 Raster／Ray Traced 半透明方法仍受全局后处理配置控制，本项目不提供逐物体切换该渲染方法的功能。

## 完整还原与性能

跨 Blender 和 UE 不保证逐像素等价；不支持的节点、介质和受视角/时间影响的效果保持近似或待复核状态。场景参考帧导出不等于所有源动画、模拟或第三方效果均可迁移。大场景 MRQ 和高精度体积设置需要按显存预算检查，桌面测试通过不是渲染验收。

局部材质切换只处理能匹配到转换记录的槽位。切换与撤销前保存相关关卡和资产；手工修改导致绑定不一致时工具会停止，避免覆盖改动。

## MMM 已弃用

MMM 独立工具暂时停止维护，现有功能仍可使用。它不参与默认一键角色流程；页面只准备环境和遥测，实际物理烘焙在 MMM 中完成。

## 部署与平台

目前面向 Windows；主程序源码启动支持 64 位 Python 3.11/3.12、UE 5.8.x。外部应用及插件版本按 [安装说明](INSTALL_WINDOWS.md) 配置。原生视口小插件必须针对实际 UE BuildId 构建。

同一个世界同时打开 Lumen 与 PT 视口时，雾可见性是世界级状态，当前不支持独立保持两套雾显示。仅切换一个活动视口，并检查最终渲染结果。
