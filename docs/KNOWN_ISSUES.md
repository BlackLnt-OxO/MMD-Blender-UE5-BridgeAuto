# 已知问题

## Ray Traced 半透明黑玻璃：暂缓

部分 Substrate 玻璃在 Ray Traced 半透明、包括开启光追折射时出现黑玻璃。当前工程使用 Blendable GBuffer；透射兼容、穿越次数、几何与光照需要进一步隔离验证，尚未确定唯一原因。

短期保留此问题，不修改全局 GBuffer、不更换引擎、不开发逐物体混合 Raster／Ray Traced 的引擎改造。常规使用继续以 Lumen 为性能目标、PT 为还原参考；详细节点与已有修复验证见 [玻璃说明](glass_nodes_validation_20261011.md)。

## 完整还原与性能

跨 Blender 和 UE 不保证逐像素等价；不支持的节点、介质和受视角/时间影响的效果保持近似或待复核状态。大场景 MRQ 和高精度体积设置需要按显存预算验证，桌面测试通过不是渲染验收。

## 部署与平台

目前面向 Windows；主程序源码启动支持 64 位 Python 3.11/3.12、UE 5.8.x。外部应用及插件版本按 [安装说明](INSTALL_WINDOWS.md) 配置。原生视口小插件必须针对实际 UE BuildId 构建。

同一个世界同时打开 Lumen 与 PT 视口时，雾可见性是世界级状态，当前不支持独立保持两套雾显示。仅切换一个活动视口，并检查最终渲染结果。
