# 场景还原 GUI 与管线边界

现有世界光、灯光、体积雾、色彩和材质转换实现标注为**路径追踪还原基线**，保留代码与既有任务。两条管线共用几何、UV、材质转换、烘焙贴图、VDB 和 HDR 环境资产，只调整 UE 光照、雾照明、半透明反射及渲染设置；路径追踪画面不作为 Lumen 验收依据。

`场景还原` 页集中显示光影还原开关、Lumen／路径追踪选择、灯光倍率、雾密度、曝光、体素精度和世界雾范围。材质策略、烘焙分辨率和其他转换参数保留在参数页，通过“打开材质与其他参数”进入。材质转换运行时无需 AI。

完成转换后可在该页读取已有任务、生成 Blender／UE 参考帧和对照，分别查看两张参考图，并复制所选管线的完整 MRQ 配置路径。资产区显示实际关卡、序列和配置；最新参考帧区按回执显示图片的实际管线与源镜头，不随管线下拉框改变旧图片的标识。查看还原报告同时显示 UE 导入报告、参考帧回执和差分结果。

光影参数用于下一次场景转换，修改后需重新导入；选择已有任务后直接切换渲染管线复用原资产，不把新倍率悄悄写入旧任务。载入配置或任务时保留记录的软件路径，即使路径尚未出现在检测列表中；后台操作开始时立即禁止切换任务或开始新导入。

新对照记录两张参考帧的哈希；更新参考帧后查看旧对照会提示重新生成。UE 渲染图有成功回执哈希时按哈希核对，拒绝把失败渲染或不匹配图片当成当前结果。历史 Lumen 回执未验证关闭路径追踪时，界面明确标注其管线尚未确认。

新任务默认 Lumen；未保存 `scene_render_pipeline` 的历史任务载入时按路径追踪基线处理。选择已有任务后可直接切换管线再渲染，复用同一导出包、同一 UE 关卡与资产，无需重新导出或烘焙；参考帧请求携带管线选择，保留原任务配置。UE 回执记录实际 MRQ 渲染 Pass、所选管线及运行时 GI／反射设置，避免混淆图片。改动源场景或烘焙参数时仍需重新转换。

Lumen 使用延迟渲染、Lumen GI 与反射；路径追踪使用独立 Path Tracer Pass。两者都使用源活动相机、参考帧、画幅和源色彩配置。参考帧生成成功仅表示渲染完成，差分指标始终保留 `needs_review`。

参考帧的完整配置保存为同一资产目录下的 `Materials/MRQ_Lumen` 或 `Materials/MRQ_PathTracing`，可直接在 UE 手动渲染中加载；`MRQ_SourceLook` 保留为共用基础配置。Lumen 的完整配置明确设置 `ShowFlag.PathTracing=0`，路径追踪配置设置为 `1`；回执同时检查运行时开关、全部渲染 Pass 并记录输出图片哈希。仅有延迟 Pass 的名称和 GI 参数不足以排除全局 ShowFlag 对实际渲染的覆盖。

完整还原需要 Blender 5.2 及内置 OpenVDB／OpenColorIO，UE 工程需要 USDImporter、OpenColorIO、MovieRenderPipeline 和 MMDBridge。安装或更新桥接后重启 UE；运行时桥接哈希与磁盘版本分别检查。UE 当前关卡未保存或渲染队列已有任务时明确提示处理，保留用户内容和队列。

GPU 专用加共享内存达到 90% 暂停、降至 80% 恢复；导入保留额外 5% 预算。导入、渲染分别处理，停止之后等待运行进程或 UE 回执结束再启动下一项。

重开工具管理的 USD 关卡时，视口恢复与 MRQ 共用的体积渲染参数；离开该关卡时恢复项目原值。此前这些参数仅在导入及 MRQ 时应用，重开编辑器后的视口可能与渲染帧不同。更新此修正后需安装桥接并重启 UE；桥接版本检查包含环境和体积模块。

设置分布：关卡内 `Source render look` 后期体积保存 Lumen GI、反射、高质量半透明反射、手动曝光和 Bloom；雾参数保存在雾 Actor 和体积材质中；完整 MRQ 配置的 `Color Output` 使用 `OCIO_Blender` 的 `Scene Linear → Blender Display`，替代 UE Tone Curve，`Console Variables` 保存体积开关和管线开关。只把 `LS_MMD` 加入 MRQ 不会自动加载这些输出设置。

视口 OCIO 是每个视口独立的显示设置，不存储在后期处理体积里。桥接按关卡和活动视口共同缓存恢复状态，切换视口时重新应用源色彩；无活动关卡视口时等待。核对画面时使用同一关卡、源相机和序列帧，视口 `Lit`、实时、曝光 `Game Settings`，并在视口 OpenColorIO 菜单确认同一转换。MRQ 默认质量覆盖和预热仍可能造成差异，实际视口一致性需要另外验收。

Lumen 管线的视口和 MRQ 共用画质设置：启用 Lumen 体积间接照明，异质体积最长 1024 步、1024 阴影图、32 位阴影精度，均匀体积雾使用 4 像素栅格和 128 深度层。Lumen 场景照明、Final Gather 和反射质量均为 2；源环境强度、雾密度、相机与材质不因此改动。离开工具管理关卡恢复原控制台值，路径追踪基线继续使用原设置。渲染回执记录实际体积控制台值，UE 报告的 `assets.render_presets` 保存两条完整配置路径。光照与雾仍有实时近似，视觉状态保留 `needs_review`。

GUI 自动参考帧在临时 PIE 世界恢复导出包中的源相机光学参数，并记录实际焦距、光圈、焦点模式和距离；不覆盖编辑器中的相机调整。手动 MRQ 使用当前序列相机。对比两种入口时，须核对镜头参数，避免将失焦差异归因于光照或雾。

玻璃通用修正保留源 Glass BSDF 对反射和透射的颜色作用，并保留背面：闭合灰玻璃的窗后内容不再因少一次透射衰减而过亮。所有透光表面使用 Surface Forward Shading；Lumen 在工具管理的后期体积中启用高质量半透明反射。该设置覆盖最前层半透明表面，多层仍受 Lumen 机制限制，见 [UE 官方说明](https://dev.epicgames.com/documentation/unreal-engine/lumen-global-illumination-and-reflections-in-unreal-engine)。镜头被前方透明板遮挡造成的屏幕折射问题按用户要求排除本轮验收。

按钮检查覆盖信号连接、配置保存／载入、场景独立预检、三类导入入口、参考帧与对照、报告、旧 FBX 命令、桥接、CameraCutAuto 帧编辑、PhysicsBakeFix 文件输出及 MMM Runtime／插件文件操作。新参考帧入口另以真实 Blender 和 UE 验证；角色烘焙和人工导出窗口的整套外部流程未因本次 GUI 检查重新验收。
