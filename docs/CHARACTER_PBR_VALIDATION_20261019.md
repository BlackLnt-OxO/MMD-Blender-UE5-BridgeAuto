## 修改内容与限制

- 独立嘴唇使用面部类型，优先继承共用图集面部的有效参数及散射遮罩；唇色、原可见性和手动覆盖保留。
- 名称未识别、分类冲突和资源缺失在材质分析列表中显示黄色；确认类型后关联唯一同名辅助图，手工文件和通道优先。缺失资源不会因选择类型而被隐藏。
- 牙齿增加釉质表面并保留原图。口腔内部遮光仍可能发灰，不能保证每种灯光下呈纯白。
- 半透明布料使用 Cloth/Fuzz，保留原透明度、MatCap 和法线；原贴图或网格问题仍会影响布感。
- 焊接／加权法向实验本身将法线传回原拓扑，不会平滑真实轮廓；可选轮廓实验先处理导出副本的真实坐标或拓扑，再计算法线，结果和限制另行验收。
- 共享 GPU 内存仍为唯一暂停依据。专用显存、DXGI 本地预算和系统内存只作遥测。

使用方式与可调参数见 [角色 PBR](CHARACTER_PBR.md)，其它限制见 [已知问题](KNOWN_ISSUES.md)。
