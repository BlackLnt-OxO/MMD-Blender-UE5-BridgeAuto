# v0.4.0 更新说明

2026-10-30 源码与 Windows 打包批次。应用、Python 项目和 EXE 文件版本统一为 0.4.0。本批保留已有任务、手工 UE 内容和旧配置的处理含义；新默认作用于新任务。

## 新增与修改

| 功能 | 行为与说明 |
|---|---|
| [六档角色几何](../CHARACTER_PBR.md#六档角色几何处理) | 新增头发不添加修改器、头发仅加权且不焊接两种策略；后者为新任务默认。前者保留原头发法线，后者重新计算；旧选择、蒙皮与表情保留。 |
| [UE 材质配置复用](../CHARACTER_MATERIAL_PRESETS.md) | 保存 UE 实际母材质及参数，确认槽位后应用、回读与撤销；支持新角色导入时复用。缺失依赖、对应冲突与后续人工修改会停止覆盖。 |
| [内置卡通渲染](../BUILTIN_CEL.md) | 基础受光、滤镜、描边三层角色，支持 PMX MatCap 和 A／B 明暗配色。滤镜母版 v2 使用 Before DOF，保留工程内 v1 手调资产；内置 PBR 仍为默认。 |
| 旧镜头切分兼容 | 补齐大纲与 Sequencer 文件夹归组、实际绑定识别、预览和半帧验证。旧脚本配置及已有分镜保留，GUI 不单独显示旧切分入口。 |
| [Frame Rate Upgrade](../USAGE.md#镜头升帧frame-rate-upgrade) | 检测并复核全部跳切；相机在新增半帧保持切前姿态，仅将指定位置已有物体键后移一帧。无键则跳过，目标冲突拒绝，保留 Add、单相机、完整备份及另存结果。 |
| MRQ 配套 | 关联源序列的队列任务指向升帧副本并采用 Frame Open，采样数沿用原设置；保存独立预设。有界后续区间由原生接口保护，避免片尾定格参与前面镜头的求值。 |

相机解析遵循唯一 Camera Cut 的明确绑定，支持相机 Actor 或其直接组件；绑定失效时拒绝猜选其它相机。升帧不会按每一帧重新烘焙镜头，不处理已经切成多个 Camera Cut 区间的序列。

## 升级与包内容

完整解压本批 `MMDBridgeForUE-Windows-x64.zip`，保留 `_internal`、文档、许可证和 `Source.zip`；校验同批 `SHA256SUMS.txt`，不要只替换 EXE。原生插件目标为 **UE 5.8.2 / BuildId 55116800**；不同 BuildId 需重新编译。

保存并关闭 UE，安装本批桥接插件，再重启并连接工程。旧 DLL 即使 BuildId 相同，也可能没有 `MMDBridgeCelCharacterActor` 或有限区间保护接口；重新连接不会替换已加载 DLL。新 Cel 母版位于 `/Game/MMDBridge/BuiltinCel/v2/`，旧资产保持原样。

Git push 更新源码；本地 ZIP 不会因此进入 Git，也不会自动替换 [v0.3.0 公开附件](https://github.com/BlackLnt-OxO/MMD-Blender-UE5-BridgeAuto/releases/tag/v0.3.0)。本次二进制包本地交付，公开 Release 附件单独发布。打包与启动检查见 [安装说明](../INSTALL_WINDOWS.md#开发与打包)。

## 已验证范围

- 完整 Python／Qt 回归：1358 通过、6 跳过；后补相机绑定保护后，39 项针对性测试通过。跳过项需要原生 NumPy／USD 或缺少本地场景夹具，没有算作通过。
- Blender 5.2.2 的 14 组几何小夹具通过；未重跑真实模型完整转换。
- UE 40 槽材质保存、应用、回读、撤销与冻结配置导入通过，包括自定义母材质、参数／静态开关／Profile 和手改保护。
- Cel 保存重载、两组角色三帧的 741 骨骼与 85 表情同步通过；9 帧 MRQ 检查了运行时材质、显隐、光照通道及可见角色顶点色。
- 已保存序列的隔离副本完成 33 个切点、7 条通道、231 项保持检查；240 fps 求值包含新增半帧，键数 41,558、Camera Cut 区间数 1。绑定使用夹具解析，不代替当前舞台实际绑定审计。
- 两个原生插件按本批源码和实际 BuildId 编译通过；短渲染使用 None、4 时域×2 空间、Frame Open。不同采样／历史缓存配置需单独验证。

MRQ 中旧舞台头发缺光，曾涉及自建叠层蓝图的临时顶点色与槽显隐未进入运行世界，以及有界相机区间提前扩展两个独立问题。本轮通用 Cel 未复现前者，未加入固定槽号或强制涂白补丁。粒子起始抖动、任意 TSR／反射历史闪烁和不同模型的艺术外观仍保留复核边界，见 [已知问题](../KNOWN_ISSUES.md#mrq-序列与运行状态)。
