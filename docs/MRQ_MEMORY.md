# 渲染与显存设置

## 先用默认配置

“场景还原 → Lumen 渲染显存策略”提供：

| 策略 | 用途 |
| --- | --- |
| 均衡（默认） | 保留硬件光追，限制缓存预算，适合先检查场景 |
| 低显存 | 进一步缩小缓存和反射分辨率，画面需要比较 |
| 兼容 | 软件 Lumen 与虚拟阴影，避开硬件光追，效果会有差异 |
| 原电影级缓存 | 较高缓存预算，显存需求更大 |

纹理池预算不是 GPU 总显存上限。几何、加速结构、体积、反射、渲染目标和其它程序都会占用显存。大场景先渲染一帧，确认画面和稳定性，再逐项提高采样或质量。

## 雾的精度

原生雾使用体积栅格，阴影和光束细节会受分辨率及距离影响。在 UE 控制台可检查／调整：

```text
r.VolumetricFog.GridPixelSize 8
r.VolumetricFog.GridSizeZ 128
```

这是默认原生雾的基础档。减小 GridPixelSize 或提高 GridSizeZ 会增加开销；例如从 8 改为 4 会提高屏幕平面上的栅格数量。先记录原值，再用短渲染比较。控制台临时值不一定在重启或 MRQ 时保留，正式输出按所用预设核对。

源雾密度与体积栅格精度是不同参数，增大密度不能修复低分辨率阴影。

## 后台渲染

先在 UE 保存关卡、序列与 MRQ 预设，再关闭编辑器并使用工具的后台入口，避免同时占用两份场景资源。详见 [后台渲染](background_render.md)。

设备移除或 GPU 崩溃不能只根据显存数字判断原因；保存相关日志、软件版本和复现步骤。在未定位之前先降低负担并验证一帧，不承诺某个固定采样组合适合所有场景。
