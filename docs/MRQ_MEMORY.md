# 显存与画质

大场景先输出一帧，确认材质和稳定性，再增加采样或渲染范围。纹理池只是显存的一部分，不是 GPU 总占用上限。

## 选择 Lumen 策略

打开“场景还原 → 渲染与显存”。

| 策略 | 取舍 |
| --- | --- |
| 均衡（默认） | 保留硬件光追，限制缓存预算，适合首次检查 |
| 低显存 | 进一步减小缓存和反射分辨率，需比较细节 |
| 兼容 | 使用软件 Lumen 与虚拟阴影，避开硬件光追，画面可能变化 |
| 原电影级缓存 | 保留更高缓存预算，显存需求更大 |

总显存占用还包括几何、光追加速结构、体积、反射、渲染目标和其它应用。

## 雾精度

默认原生雾的基础值为：

```text
r.VolumetricFog.GridPixelSize 8
r.VolumetricFog.GridSizeZ 128
```

减小 GridPixelSize 会增加屏幕平面栅格，提高 GridSizeZ 会增加深度层。它们影响阴影和光束细节，也提高开销；增大雾密度不能补偿低分辨率。

先记录原值，用同一帧比较。控制台临时修改未必在重启或 MRQ 时保留，正式输出核对实际预设。

## 遇到卡顿或设备移除

1. 保存 UE 日志和本次任务记录，记下引擎、驱动和画质配置。
2. 关闭不必要的其它 GPU 任务；后台渲染前保存并关闭目标 UE 编辑器。
3. 降低缓存、画幅、体积或采样中的一项，输出单帧检查，再逐项调整。
4. 每次只调整一类参数，记录前后结果。

渲染自动显存保护默认关闭，占用采样和峰值记录仍保留；导入／导出的保护与它分开。设备移除也可能来自驱动、材质或引擎问题，不能只凭某次显存数字归因。

所有显存保护的暂停与恢复判断仅使用共享显存占用比例。专用显存、DXGI 本地预算与系统内存只用于观测，不触发保护；共享显存数据不可用时不回退到这些指标，已暂停的导入等待有效共享显存采样后才自动恢复。

输出步骤见 [后台渲染](background_render.md)，画面对照见 [场景光影](SCENE_APPEARANCE.md)。
