# v0.3.0 界面截图

本目录用于项目首页和现行使用文档，截图日期为 2026-10-25，应用版本为 0.3.0，源码基线为 `77e2b20e1778fd27b8bc7370a1d2264c4e67772d`。

图片由实际 PySide6 主窗口直接捕获，保留 1600×1180 原始输出，未裁切、缩放、拼接或修改像素。逻辑窗口为 1280×944，显示缩放为 125%。左侧工作区包含“素材与软件、参数、角色设置、场景还原、任务与日志”。

素材路径和软件条目均为文档示例。捕获使用独立配置，未执行软件探测、连接 UE 或启动转换。任务与工具页面保留“未启动”“未检测”等实际初始状态；依赖任务或 UE 连接的按钮可能禁用，截图不代表导入、检测或渲染已经完成。
