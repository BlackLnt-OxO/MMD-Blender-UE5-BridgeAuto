# 场景灯光、雾与参考图

## 默认设置

新场景任务默认启用“还原世界光、灯光、体积雾与源色彩”，使用 Blender 5.2、UE 5.8 和 Lumen。旧任务恢复时沿用它的已保存配置。

工具转换源世界、渲染可见灯光和可支持的雾输入。灯光亮度倍率、雾密度倍率和曝光补偿可独立调整。倍率不替代场景的原参数；先使用默认值检查源相机和曝光，再调整画面。

## 雾中受光与遮挡

默认 **原生体积雾** 用于 Lumen，计算灯光注入、遮挡和体积散射。它不预烘焙固定光束，遮挡变化可影响雾中的光。

路径追踪对照保留源雾表达，作为效果参考。两种渲染器不会在所有介质、玻璃、焦散或多次散射上完全一致。Lumen 的原生雾不自动求解玻璃透镜折射后的聚光。

其它 SVT 异质体积选项仍属于实验性方案，部分配置开销明显更高。常规使用保留原生雾；未知节点、多介质与细结构可能需要人工调整。

雾光的细节受体积栅格、灯光阴影和场景距离影响。提高精度会增加显存与耗时，不会自动修复源材质或透明遮挡的所有问题。

## 参考帧对照

1. 在 Blender 设置活动相机、画幅和要比较的场景帧。
2. 在“场景还原”选择已转换的场景任务。
3. 点击“渲染 Blender 参考帧”。
4. 选择 Lumen 或路径追踪，点击“渲染 UE 参考帧”。
5. 用“生成对照与差分”检查差异；可打开原图或复制对应 MRQ 配置路径。

选择管线不会把旧图片重新解释成该管线；页面显示实际最新渲染回执。渲染完成仍需检查画面，差分不能单独证明材质还原正确。

## 使用限制

在同一个世界中同时打开 Lumen 和 PT 视口，当前雾可见性状态不能分别保持。使用一个活动视口切换，并检查最终输出。

玻璃折射、多层透明、未知节点与高密度体积的限制见 [已知问题](KNOWN_ISSUES.md)。后台输出方法见 [后台渲染](background_render.md)。
