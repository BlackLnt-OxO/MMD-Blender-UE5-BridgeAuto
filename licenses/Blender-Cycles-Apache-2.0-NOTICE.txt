scene_shader_data.py contains a Python compatibility port of the uint hash,
object random mapping and disjoint-set algorithm used by Blender Cycles.

Changes: translated uint arithmetic to explicit 32-bit Python arithmetic;
preserved float32 rounding; wrote the scalar attribute to a distinct UV carrier.
